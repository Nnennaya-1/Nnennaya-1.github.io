# Faith Nnenna Orji — Portfolio

A static portfolio website. No installation or build step is needed.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Create a public GitHub repository, such as portfolio, or YOUR-USERNAME.github.io for a site at your account root.
3. Upload the extracted contents directly into the repository. index.html and the assets folder must be at the repository root. Do not upload the ZIP itself or put the files inside an extra folder.
4. Commit the files to main.
5. Open Settings > Pages. Under Build and deployment, select Deploy from a branch, then main and /(root). Click Save.
6. When deployment completes, GitHub displays the live site address in Settings > Pages.

Includes light/dark mode, project previews, local fonts, photos and selected portfolio evidence. Theme choices are stored only in the visitor’s browser. Photos are credited in PHOTO_CREDITS.md and relevant project previews.

Changes made later to the ChatGPT-hosted site do not automatically update this GitHub copy. Update the corresponding repository files to publish future changes.
